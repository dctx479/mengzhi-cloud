========================================
6. 错误处理
========================================

错误码体系:
- 10xxx: 参数错误 (HTTP 400)
- 20xxx: 认证授权错误 (HTTP 401/403)
- 40xxx: 数据库错误 (HTTP 4xx)
- 50xxx: 系统错误 (HTTP 500)

常用错误码:
✓ 10001 - 参数验证失败
✓ 10005 - 参数值无效
✓ 20020 - 权限不足
✓ 40010 - 产品不存在
✓ 40011 - SKU已存在
✓ 50000 - 系统错误

统一的错误响应格式:
{
  "code": 错误码,
  "message": "错误消息",
  "data": null,
  "errors": [...],
  "timestamp": "ISO8601",
  "request_id": "uuid-v4"
}

8. 使用示例
========================================

curl获取列表:
curl "http://localhost:8000/api/v1/products?page=1&size=10&category=肉类"

curl创建产品:
curl -X POST "http://localhost:8000/api/v1/products" \
  -H "Authorization: Bearer token" \
  -H "Content-Type: application/json" \
  -d '{...}'

curl获取详情:
curl "http://localhost:8000/api/v1/products/1"

curl更新产品:
curl -X PUT "http://localhost:8000/api/v1/products/1" \
  -H "Authorization: Bearer token" \
  -d '{...}'

curl删除产品:
curl -X DELETE "http://localhost:8000/api/v1/products/1" \
  -H "Authorization: Bearer token"

Python SDK:
from app.services.product_service import ProductService
service = ProductService(db)
product = service.create_product(request, user_id)
products, total = service.list_products(page=1, size=10)
