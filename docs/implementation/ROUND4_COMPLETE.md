## 🚀 使用示例

### 记录对话使用

```python
from app.services.usage_stats import UsageStatsService

stats_service = UsageStatsService(db)

# 客户端收费¥0.1，后台统计实际成本
stats_service.record_chat_usage(
    enterprise_id=123,
    user_id=456,
    model="deepseek",
    input_tokens=1000,
    output_tokens=2000,
    client_charge=Decimal("0.1"),  # 客户端收费
    backend_cost=Decimal("0.5")    # 后台成本
)
```

### 配置模型（Web面板）

1. 访问 `/enterprise/model-config`
2. 选择模型（DeepSeek/千问/智谱/自定义）
3. 输入API密钥
4. 配置Base URL（可选）
5. 设置优先级
6. 保存并测试连接
