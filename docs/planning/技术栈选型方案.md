## 技术架构总览

### 整体架构风格
**微服务架构 + 前后端分离 + AI能力层**


## 前端技术栈详解

### 1. Web端技术栈

#### 1.1 核心框架

**Vue 3.4+ (Composition API)**
- **选型理由**：
  - 性能优秀，渲染速度比Vue 2提升40%
  - Composition API代码组织更灵活，易于复用
  - TypeScript支持完善
  - 生态成熟，组件库丰富
  - 学习曲线相对平缓，适合小团队
- **官网**：https://vuejs.org
- **版本建议**：3.4+

**TypeScript 5.0+**
- **选型理由**：
  - 强类型检查，减少运行时错误
  - 智能提示，提升开发效率
  - 代码可维护性强
  - 与Vue 3配合完美
- **官网**：https://www.typescriptlang.org
- **版本建议**：5.0+

#### 1.2 构建工具

**Vite 5.0+**
- **选型理由**：
  - 极速的开发服务器启动（冷启动<1s）
  - 热模块替换（HMR）快速响应
  - 生产构建基于Rollup，打包优化
  - 插件生态丰富
- **官网**：https://vitejs.dev
- **替代方案**：Webpack（更适合复杂配置需求）

#### 1.3 状态管理

**Pinia 2.0+**
- **选型理由**：
  - Vue 3官方推荐的状态管理方案
  - TypeScript支持完善
  - API简洁，易于学习
  - DevTools支持好
  - 支持模块化、插件化
- **官网**：https://pinia.vuejs.org
- **替代方案**：Vuex 4（旧项目迁移）

#### 1.4 路由管理

**Vue Router 4.0+**
- **选型理由**：
  - Vue 3配套路由方案
  - 支持动态路由、嵌套路由
  - 路由守卫功能完善
  - TypeScript支持
- **官网**：https://router.vuejs.org

#### 1.5 UI组件库

**Element Plus 2.0+**
- **选型理由**：
  - 基于Vue 3，组件丰富（80+）
  - 中文文档完善
  - 主题定制方便
  - 社区活跃
- **官网**：https://element-plus.org
- **替代方案**：
  - Ant Design Vue（适合企业级后台）
  - Naive UI（轻量级，TypeScript原生）

#### 1.6 HTTP客户端

**Axios 1.6+**
- **选型理由**：
  - 最流行的HTTP库
  - 拦截器功能强大
  - 支持请求/响应转换
  - 支持取消请求
  - 浏览器和Node.js通用
- **官网**：https://axios-http.com

#### 1.7 数据可视化

**ECharts 5.0+**
- **选型理由**：
  - 功能强大，图表类型丰富
  - 百度开源，文档完善
  - 性能优秀，支持大数据量
  - 配置灵活
- **官网**：https://echarts.apache.org
- **辅助库**：vue-echarts（Vue 3封装）

**D3.js 7.0+**（知识图谱可视化）

**VueUse 10.0+**

**Day.js 1.11+**（日期处理）

## 后端技术栈详解

### 1. Web框架

**FastAPI 0.109+**
- **选型理由**：
  - 高性能（基于Starlette和Pydantic）
  - 原生异步支持（async/await）
  - 自动生成OpenAPI文档
  - 类型注解自动验证
  - 开发效率高
  - 现代化Python Web框架
- **官网**：https://fastapi.tiangolo.com
- **性能对比**：
  - 比Flask快2-3倍
  - 与Node.js、Go性能相当
- **替代方案**：
  - Django REST Framework（适合传统MVC项目）
  - Flask（轻量，但异步支持弱）

### 2. ORM框架

**SQLAlchemy 2.0+**
- **选型理由**：
  - Python最成熟的ORM
  - 2.0版本全面支持异步
  - 支持多种数据库
  - 查询构建器强大
- **官网**：https://www.sqlalchemy.org

**Alembic 1.13+**（数据库迁移）
- **选型理由**：
  - SQLAlchemy官方迁移工具
  - 版本控制清晰
  - 支持自动生成迁移脚本
- **官网**：https://alembic.sqlalchemy.org

### 3. 异步任务队列

**Celery 5.3+**
- **选型理由**：
  - Python异步任务处理标准方案
  - 支持多种消息队列（Redis、RabbitMQ）
  - 功能丰富（定时任务、任务链、任务组）
  - 监控工具完善（Flower）
- **官网**：https://docs.celeryq.dev
- **消息队列**：Redis（轻量级、速度快）

### 4. API文档

**OpenAPI (Swagger) 3.1**
- **选型理由**：
  - FastAPI自动生成
  - 交互式文档
  - 支持在线测试
- **访问路径**：`/docs`（Swagger UI）、`/redoc`（ReDoc）

### 5. 身份认证

**PyJWT 2.8+**（JWT Token）
- **选型理由**：
  - JWT标准实现
  - 无状态，易扩展
- **官网**：https://pyjwt.readthedocs.io

**python-jose 3.3+**（JWT + 加密）
- **选型理由**：
  - 支持多种加密算法

- **官网**：https://github.com/mpdavis/python-jose

**Passlib 1.7+**（密码加密）

## AI/算法技术栈详解

### 1. 大语言模型

**DeepSeek API**
- **选型理由**：
  - 项目文档指定
  - 中文理解能力强
  - 成本相对较低
  - API稳定
- **官网**：https://www.deepseek.com
- **定价**：约0.001元/千tokens
- **备用方案**：
  - 阿里云通义千问（文档提到）
  - 百度文心一言
  - 智谱ChatGLM

**官方SDK**：
```python
pip install openai  # DeepSeek兼容OpenAI SDK
```

### 2. LLM应用框架

**LangChain 0.1+**
- **选型理由**：
  - RAG架构成熟方案
  - 与主流LLM集成良好
  - Prompt管理便捷
  - 链式调用灵活
  - 内存管理完善
  - 社区活跃
- **官网**：https://python.langchain.com
- **核心组件**：
  - LLMs（大语言模型）
  - Prompts（提示词模板）
  - Chains（链式调用）
  - Memory（对话记忆）
  - Agents（智能代理）
  - Vector Stores（向量存储）

**LangSmith**（可选，LLM调试工具）
- **用途**：Prompt调试、性能监控
- **官网**：https://smith.langchain.com

### 3. 向量化模型

**SentenceTransformers 2.3+**
- **选型理由**：
  - 丰富的预训练模型
  - 易于Fine-tuning
  - 多语言支持
- **官网**：https://www.sbert.net

**推荐预训练模型**：
- **text2vec-chinese**：中文语义相似度
- **m3e-base**：中文Embedding专用
- **paraphrase-multilingual-MiniLM**：多语言支持

**模型下载**：
```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('shibing624/text2vec-base-chinese')
```

### 4. 向量数据库

**Milvus 2.3+**
- **选型理由**：
  - 专为向量检索优化
  - 支持多种索引类型（IVF、HNSW、FLAT等）
  - GPU加速支持
  - 分布式扩展
  - 开源免费
  - 中国团队开发，文档完善
- **官网**：https://milvus.io
- **SDK**：pymilvus
- **部署方式**：
  - Docker Compose（单机）
  - Kubernetes（集群）
  - Milvus Lite（嵌入式）

**索引类型选择**：
- **FLAT**：精确搜索，小数据量（<10万）
- **IVF_FLAT**：平衡精度和速度，中等数据量（10万-100万）
- **IVF_PQ**：压缩存储，大数据量（>100万）
- **HNSW**：高精度高速度，内存充足时首选

**替代方案**：
- **Faiss**（Facebook开源，更轻量）
- **Pinecone**（云服务，付费）
- **Weaviate**（开源，GraphQL查询）

### 5. 知识图谱

**Neo4j 5.0+**
- **选型理由**：
  - 最成熟的图数据库
  - Cypher查询语言简洁强大
  - 可视化工具完善（Neo4j Browser）
  - ACID事务支持
  - 社区版免费
- **官网**：https://neo4j.com
- **SDK**：py2neo 或 neo4j-driver

**Cypher查询示例**：
```cypher
// 查询产品的文化关联
MATCH (p:Product {name: '乌兰察布马铃薯'})-[:RELATED_TO]->(c:Culture)
RETURN p, c
```

**可视化工具**：
- Neo4j Browser（内置）
- Neo4j Bloom（高级可视化，收费）
- yFiles（图布局算法）

**替代方案**：
- **JanusGraph**（超大规模图，分布式）
- **ArangoDB**（多模型数据库）

### 6. NLP工具

**spaCy 3.7+**（实体抽取）
- **选型理由**：
  - 工业级NLP库

- **官网**：https://github.com/fxsjy/jieba

### 7. 机器学习框架

**PyTorch 2.1+**（模型训练）

**Transformers 4.36+**（Hugging Face）

### 8. 模型推理优化

## 数据库技术栈详解

### 1. 关系数据库

**MySQL 8.0+**
- **选型理由**：
  - 最流行的开源数据库
  - 性能优秀
  - 支持JSON字段
  - 云服务支持好（阿里云RDS、腾讯云）
  - 生态成熟
- **官网**：https://www.mysql.com
- **特性**：
  - InnoDB存储引擎（ACID）
  - 全文索引
  - JSON字段支持
  - 窗口函数
  - CTE（公用表表达式）

**配置建议**：
```ini
# my.cnf
[mysqld]
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci
max_connections=500
innodb_buffer_pool_size=1G
innodb_log_file_size=256M
```

**替代方案**：
- **PostgreSQL 15+**（更适合复杂查询和地理信息）
- **MariaDB 11+**（MySQL分支，某些特性更强）

### 2. 图数据库

**Neo4j 5.0+ Community Edition**
