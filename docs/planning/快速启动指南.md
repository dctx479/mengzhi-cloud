#### 2.3 本地开发环境搭建

**前端环境**：
```bash
cd frontend

# 创建Vue 3项目
pnpm create vite . --template vue-ts
# 项目名：frontend
# 模板：vue-ts

# 安装依赖
pnpm install

# 安装必要的包
pnpm add vue-router@4 pinia axios element-plus
pnpm add -D @types/node sass

# 启动开发服务器
pnpm dev
# 访问 http://localhost:5173
```

**后端环境**：
```bash
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# 安装FastAPI及相关依赖
pip install fastapi uvicorn sqlalchemy alembic python-dotenv pydantic-settings

# 创建基础文件结构
mkdir -p app/{api,core,models,schemas,services}
touch app/__init__.py app/main.py

# 创建简单的FastAPI应用
cat > app/main.py << EOF
from fastapi import FastAPI

app = FastAPI(title="内蒙古农畜产品AI平台 API")

@app.get("/")
def read_root():
    return {"message": "欢迎使用内蒙古农畜产品AI平台API"}

@app.get("/health")
def health_check():
    return {"status": "healthy"}
EOF

# 启动开发服务器
uvicorn app.main:app --reload
# 访问 http://localhost:8000
# API文档：http://localhost:8000/docs
```

**数据库环境（Docker）**：
```bash
cd ../

# 创建docker-compose.yml
cat > docker-compose.yml << EOF
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: agri-mysql
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: agri_platform
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:7-alpine
    container_name: agri-redis
    ports:
      - "6379:6379"

  neo4j:
    image: neo4j:5.0
    container_name: agri-neo4j
    ports:
      - "7474:7474"  # Web界面
      - "7687:7687"  # Bolt协议
    environment:
      NEO4J_AUTH: neo4j/password123

volumes:
  mysql_data:
EOF

# 启动所有数据库
docker-compose up -d

# 验证
docker ps  # 查看运行中的容器
```

## 三、开发规范与最佳实践

### 3.1 Git工作流

**分支策略**：
```bash
main           # 主分支，稳定版本
  ├─ dev       # 开发分支
  │   ├─ feature/user-auth    # 功能分支
  │   ├─ feature/ai-chat      # 功能分支
  │   └─ bugfix/login-error   # Bug修复分支
```

**开发流程**：
```bash
# 1. 从dev创建功能分支
git checkout dev
git pull origin dev
git checkout -b feature/user-auth

# 2. 开发并提交
git add .
git commit -m "feat: 添加用户注册功能"

# 3. 推送到远程
git push origin feature/user-auth

# 4. 创建Pull Request/Merge Request
# 代码审查通过后合并到dev

# 5. 定期将dev合并到main
git checkout main
git merge dev
git push origin main
```

### 3.3 接口设计规范

**RESTful API约定**：
```
GET    /api/v1/users          # 获取用户列表
GET    /api/v1/users/:id      # 获取单个用户
POST   /api/v1/users          # 创建用户
PUT    /api/v1/users/:id      # 更新用户
DELETE /api/v1/users/:id      # 删除用户
```

**统一响应格式**：
```json
// 成功响应
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "username": "test"
  }
}

// 错误响应
{
  "code": 400,
  "message": "用户名已存在",
  "data": null
}
```

## 四、常见问题与解决方案

### Q1: Docker容器启动失败？
```bash
# 查看容器日志
docker logs agri-mysql
docker logs agri-redis

# 重启容器
docker-compose down
docker-compose up -d

# 清理所有容器（谨慎使用）
docker system prune -a
```

### Q2: 前端跨域问题？
```typescript
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true
      }
    }
  }
})
```

### Q3: Python依赖安装失败？
```bash
# 使用国内镜像源
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <package>

# 或配置永久镜像源
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q4: Git提交失败？
```bash
# 查看状态
git status

# 如果有冲突，手动解决后
git add .
git commit -m "fix: 解决冲突"

# 如果提交信息写错
```
