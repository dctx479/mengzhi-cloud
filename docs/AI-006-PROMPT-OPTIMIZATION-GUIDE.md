## 系统概述

### 优化前后对比

| 方面 | 优化前 | 优化后 | 改进 |
|------|-------|-------|------|
| 模板数量 | 7个基础模板 | 20+个细分模板 | +186% |
| 风格支持 | 单一风格 | 4-5种风格变体 | 5倍 |
| 文化融合 | 基本 | 深度融合(8个文化维度) | 完全 |
| 受众定位 | 通用受众 | 4个核心受众细分模型 | 精准化 |
| 质量控制 | 基础检查 | 15项质量标准 | 系统化 |
| 内容参考 | 无 | 详细示例和最佳实践库 | 完善 |

### 关键改进

#### 1. 文化元素深度融合
- **文化维度**: 草原意象 + 游牧传统 + 地理标志 + 民族精神
- **融合方式**: 比喻、拟人、场景、背景等多种方式
- **应用范围**: 产品文案、广告语、社交媒体、视频脚本

#### 2. 多风格模板体系
- **产品文案**: 专业、亲切、情感、创意 (4种风格)
- **广告语**: 古典、现代、文化融合、情感 (4种风格)
- **社交媒体**: 小红书、抖音、微博、微信 (4个平台)
- **视频脚本**: 15秒、30秒、60秒、120秒 (4个规格)

#### 3. 目标受众精准定位
- **高端消费者**: 注重品质和品牌，推荐专业/情感风格
- **年轻职业人**: 快节奏生活，推荐亲切/创意风格
- **家庭消费者**: 重视安全性，推荐专业/亲切风格
- **美食爱好者**: 对工艺有认知，推荐亲切/情感/创意风格

#### 4. 完整的内容生成能力
支持从战略规划到执行的全链路:
- 战略层: 营销方案、品牌定位
- 内容层: 产品文案、广告语、社交媒体
- 执行层: 短视频脚本、直播脚本

## 核心优化内容

### 1. 产品文案模板优化

#### 专业权威风格

**适用场景**:
- 官方网站产品页面
- B2B营销文案
- 产品手册和白皮书
- 媒体宣传稿

**核心要素** (百分比):
- 文化融入: 20% - 自然体现产地特色和工艺
- 权威背书: 30% - 认证、奖项、数据支撑
- 卖点突出: 30% - 产品独特价值和竞争优势
- 情感共鸣: 15% - 触及消费者价值观
- 其他: 5%

**优化前**: "这是内蒙古最好的黄油"
**优化后**: "源自内蒙古原生态牧场，获有机认证，采用传统游牧工艺结合现代低温技术制造，富含天然omega-3，营养学指标领先行业..."

#### 亲切友好风格

**适用场景**:
- 社交媒体笔记
- 微博推文
- 公众号文章
- 社区分享

**写作技巧**:
- 使用第一人称("我"、"我们")
- 分享真实经历和感受
- 场景化描写具体使用时刻
- 表现真实的痛点和解决

**示例**:
```
今天想推荐一个改变了我早餐的产品——内蒙古有机黄油。

用了差不多一个月，最直接的感受就是肠胃变舒服了。
之前用的黄油有些油腻感，现在这款非常顺滑，涂在面包上就像沙漠上的一层金色阳光。

最喜欢它的是真的没有那种塑料味的人工香料，吃到的就是纯粹的牛油香气。
我妈尝了一次就要求我每个月给她寄一盒...
```

#### 情感共鸣风格

**故事框架**:
1. **开场钩子** (10%): 引发情感共鸣
2. **故事主体** (60%): 讲述产品来源和品牌故事
3. **转折升华** (20%): 体现深层意义
4. **结尾落点** (10%): 精神鼓舞

#### 创意新颖风格

**创意思路**:
- 打破既有认知
- 用反差制造吸引
- 创意比喻和拟人
- 感官创意表现

### 2. 广告语生成优化

#### 从基础模板到精准生成

**关键改进**:
- 明确的创意技巧指导
- 多维度的差异化要求
- 情感触发点的精准设定
- 文化元素的自然融合

**质量标准**:
- 长度: 8-15字(记忆黄金长度)
- 节奏: 朗朗上口，易于传播
- 差异: 明确区别于竞品
- 文化: 自然融入地域元素
- 情感: 能触发目标情感

**优化示例**:

优化前的广告语:
```
1. 内蒙古黄油很好吃
2. 我们的黄油很纯正
3. 买我们的黄油吧
```

优化后的广告语:
```
1. 草原黄金，健康之选
2. 游牧工艺，现代品质
3. 天然黄油，信任之味
4. 每一口都是草原的馈赠
5. 纯正黄油，代代传承
```

### 3. 社交媒体文案优化

#### 小红书种草笔记

**核心特点**:
- 真实体验分享
- 详细的使用细节
- 亲切的社区气氛
- 高互动性

**结构优化**:
```
标题(吸引停留)
    ↓
开场(痛点/场景) - 100字
    ↓
产品介绍(亮点列举) - 200字
    ↓
真实体验(使用感受) - 200字
    ↓
推荐理由(为什么好) - 100字
    ↓
行动号召(购买指引) - 50字
    ↓
标签体系(分类+细分)
```

**小红书标题公式**:
- 悬念式: "内蒙古这个宝藏特产，改变了我的X"
- 干货式: "5款内蒙古特产，冬天必囤清单"
- 情感式: "尝过这个，我再也回不到普通黄油"
- 对比式: "vs 欧洲黄油，为什么我选择内蒙古"

#### 抖音短视频文案

**钩子设计** (前3秒最关键):
- 视觉冲击: 高对比色、快速转切、炫彩特效
- 文案冲击: "我后悔没早点买..."、"这才是真正的..."
- 情感冲击: 惊喜、共鸣、笑点

**文案要求**:
- 每句≤15字
- 口语化表达
- 节奏感强
- 融入地域元素

#### 微博话题文案

**特点**:
- 话题驱动传播
- 强调互动讨论
- 实时热点敏锐
- 传播效应快

**互动设计**:
- 评论引导: "你最喜欢的内蒙古特产是什么？"
- 投票互动: "你觉得这个产品和XX的差异在哪？"
- 转发激励: "转发并评论，抽奖送..."

### 4. 短视频脚本优化

#### 完整脚本框架

**15秒快速种草**:
- 钩子(0-3秒): 快速吸引
- 痛点(3-8秒): 问题表述
- 解决(8-12秒): 产品介绍
- CTA(12-15秒): 行动号召

**30秒标准宣传**:
- 钩子(0-3秒): 视觉冲击
- 场景(3-10秒): 生活场景
- 产品(10-25秒): 详细展示
- CTA(25-30秒): 购买指引

**60秒完整故事**:
- 钩子(0-3秒)
- 痛点(3-10秒)
- 故事(10-40秒)
- 产品(40-55秒)
- CTA(55-60秒)

#### 脚本要素

**画面设计**:
- 机位: 正面、侧面、俯视角多变化
- 转场: 切割、淡入淡出、动画转场
- 特效: 适度使用，不过度

**文案设计**:
- 每句话≤15字
- 与画面同步
- 字体大小适中
- 关键词突出

**音效设计**:
- BGM: 根据内容选择节奏感
- 音效: 关键转折点强调
- 配音: 节奏与画面匹配

---

### 5. 营销方案优化

从简单模板到完整战略规划

**新增核心内容**:
1. **战略层面**: SWOT分析、市场定位、差异化策略
2. **执行层面**: 详细的活动计划、内容日历、时间表
3. **评估层面**: KPI拆解、监测方法、优化机制
4. **风险管理**: 风险识别、应对方案、应急预案

**方案结构**:
```
营销目标(SMART)
    ↓
受众分析(4个维度)
    ↓
核心策略(5个方向)
    ↓
活动计划(3-5个活动)
    ↓
内容规划(发布日历)
    ↓
执行时间表(甘特图)
    ↓
效果评估(KPI体系)
    ↓
预算分配(详细预算)
    ↓
风险管理(应对预案)
```

## 最佳实践

### 1. 文化融合的艺术

#### ❌ 错误示范 (生硬堆砌)
```
这是来自内蒙古的产品。
产品采用游牧民族传统工艺。
内蒙古是广阔的草原。
这个产品是地理标志产品。
```

#### ✅ 正确示范 (自然融合)
```
如同草原的广阔和纯净，这个产品承载了蒙古族
千年的制作智慧。在蓝天白云下，牧民们用最
古老的手工技艺，将草原的精华浓缩进每一口。

这不仅是一个产品，更是一段民族文化的传承。
```

#### 融合技巧

| 技巧 | 示例 |
|------|------|
| 比喻 | "如同草原的金色阳光，这个黄油..." |
| 拟人 | "产品仿佛在诉说蒙古族的故事..." |
| 场景 | "在毡房的篝火前，奶茶的温度..." |
| 背景 | "源自内蒙古草原，采用传统工艺..." |
| 意象 | "天然纯净，就像星空一样..." |

### 2. 目标受众的精准定位

#### 受众分析框架

```python
audience_analysis = {
    "segment": "高端消费者",

    # 人口特征
    "demographics": {
        "age": "30-55岁",
        "income": "50万+年收入",
        "education": "本科及以上"
    },

## 常见问题

### Q1: 如何选择合适的文案风格?

**A**: 根据以下矩阵选择:

```
受众 / 场景:
- 高端消费者 + 官方渠道 → 专业风格
- 年轻用户 + 社交媒体 → 亲切/创意风格
- 品牌故事传播 → 情感风格
- 需要突破和创新 → 创意风格
```

### Q2: 文化元素可能显得生硬，如何避免?

**A**: 关键是"融入"而非"强调":
1. 使用比喻和拟人，而不是直接陈述
2. 文化元素应该是背景，不是主题
3. 测试: 去掉文化元素，文案是否仍然成立?
4. 多用场景和细节，而不是宏大叙述

### Q3: 如何判断生成的内容质量?

**A**: 使用15项质量标准检查:
- 文化融合: 自然度、准确度、适度性
- 卖点表述: 清晰性、说服力、差异化
- 受众匹配: 语言适配、痛点触达、价值体现
- 表达质量: 流畅度、专业度、记忆度
- 总体评分 ≥ 80分为优秀

### Q4: 能否混合使用多个模板?

**A**: 可以，建议:
1. 产品文案作为基础
2. 结合社交媒体模板针对不同平台
3. 使用短视频脚本做视频内容
4. 定期参考营销方案做整体规划

### Q5: 模板中有些参数不清楚，如何处理?

**A**:
1. 参考提供的示例
2. 使用 `/examples` API端点获取示例
3. 查看配置文件中的详细说明
4. 渲染时验证会提示缺少哪些参数

## API文档

### 基础信息

**Base URL**: `http://localhost:8000/api/v1`

**认证**: 根据项目配置(JWT/API Key等)

**响应格式**: JSON

### 端点汇总

#### 1. 获取模板列表
```
GET /prompts/templates

**响应**:
```json
{
  "templates": [

      "name": "product_copy_professional",
      "description": "专业权威风格的产品文案..."
    }

```

#### 2. 渲染Prompt
```
POST /prompts/render
Content-Type: application/json

{
  "template_type": "product_copy",
  "style": "professional",
  "context": {
    "product_name": "内蒙古有机黄油",
    "category": "乳制品",
    ...
  }
}
```

**响应**:
```json
{
  "success": true,
  "prompt": "# 角色设定\n你是一位深谙..."
}
```

#### 3. 验证上下文
```
POST /prompts/validate
Content-Type: application/json

{
  "template_type": "product_copy",
  "context": {...}
}
```

#### 4. 获取文化关键词
```
GET /prompts/cultural-keywords?category=grassland
```

**响应**:
```json
{
  "keywords": {
    "grassland": ["草原", "蓝天", "白云", ...]
  }
}
```

```
POST /prompts/product-copy/quick

{

```

### 错误处理

| 错误码 | 说明 | 处理方式 |
|--------|------|---------|
| 400 | 参数错误或缺少必需字段 | 检查请求参数 |
| 404 | 模板不存在 | 调用 `/templates` 获取可用列表 |
| 500 | 服务器错误 | 检查日志，联系技术支持 |
