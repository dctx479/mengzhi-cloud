## 一、项目背景与目标

### 1.1 项目定位

**蒙智云**（mengzhi-cloud）是面向内蒙古中小农畜产品企业的**SaaS化AI营销赋能平台**，通过AI能力降低品牌营销门槛，助力"原产地故事"向"消费端价值"高效转化。

### 1.2 核心差异化价值

| 维度 | 价值点 | 实现方式 |
|------|--------|---------|
| **文化IP** | 草原文化特色智能体 | 小数（文化传承者）+ 小商（营销顾问）双IP |
| **知识赋能** | 产品-文化-品牌关联 | 知识图谱 + 文化溯源 |
| **营销闭环** | 从内容创作到效果监测 | 多平台适配 + 数据分析 |
| **降本提效** | 替代3-5人营销团队 | AI自动化 + 模板化 |

### 1.3 现状诊断

**已完成能力**（mengzhi-cloud v1.1）：
- ✅ 用户管理与认证
- ✅ 产品管理（CRUD + 京东/淘宝导入）
- ✅ 基础智能客服（通用问答）
- ✅ 订单管理 + 支付集成
- ✅ 5层用户画像系统
- ✅ 个性化推荐引擎
- ✅ 基础内容生成（文案）

**关键缺失能力**（大创申报要求）：
- 🔴 **文化IP智能体**：无小数/小商双IP，无草原文化特色
- 🔴 **知识图谱**：仅有简单标签库，无产品-文化溯源链路
- 🔴 **营销场景闭环**：无直播脚本生成、无多平台适配、无效果监测

## 六、关键技术方案

### 6.1 IP智能体架构

```python
# 核心设计模式：双Agent + Router

IPRouter
    ├─ intent_detection(user_message)  # 意图识别
    │   └─ return: IPType (xiaoshu / xiaoshang)
    │
    ├─ XiaoshuAgent (草原文化传承者)
    │   ├─ system_prompt: 草原文化人设
    │   ├─ generate_response()
    │   ├─ generate_brand_story()
    │   └─ generate_cultural_tracing()
    │
    └─ XiaoshangAgent (品牌营销顾问)
        ├─ system_prompt: 营销专家人设
        ├─ generate_response()
        ├─ generate_live_script()
        └─ generate_content_for_platform()
```

**关键技术点**：
- Prompt工程：System Prompt + Few-shot Examples
- 上下文管理：用户画像 + 对话历史 + 产品信息
- 缓存策略：Redis缓存相似问题，降低LLM调用
- 降级机制：LLM超时/失败时返回模板回复

### 6.2 知识图谱设计

**方案选择：MySQL增强版（Phase 1）**

```sql
-- 核心表结构
cultural_elements          -- 文化元素库
origin_culture_relation    -- 产地-文化关联
product_culture_trace      -- 产品溯源链路
brand_stories              -- 品牌故事库
```

**查询示例**：
```python
# 查询产品的文化溯源
def get_product_cultural_trace(product_id):
    # 产品 → 产地 → 文化元素 → 故事
    return {
        "product": {...},
        "origin": {...},
        "cultures": [{type, name, story}, ...],
        "auto_story": "..."  # 自动拼接故事
    }
```

**Neo4j升级路径（Phase 2，可选）**：
- 触发条件：产品数 >500 或 需要3跳+关联查询
- 迁移方案：双写 → 切流量 → 下线MySQL

### 6.3 LLM调用策略

```python
# 成本优化策略
class LLMCallStrategy:
    def call_with_cache(self, prompt, user_id):
        # 1. 检查Redis缓存（相似度>0.9）
        cache_key = f"llm:{hash(prompt[:100])}"
        cached = redis.get(cache_key)
        if cached:
            return cached
        
        # 2. 调用LLM
        response = anthropic.messages.create(
            model="claude-sonnet-4-20250514",
            max_tokens=1000,
            system=system_prompt,
            messages=[{"role": "user", "content": prompt}]
        )
        
        # 3. 缓存结果（TTL=1小时）
        redis.setex(cache_key, 3600, response.content)
        
        # 4. 记录成本
        log_token_usage(user_id, response.usage)
        
        return response.content
```
