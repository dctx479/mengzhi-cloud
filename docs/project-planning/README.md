## 📊 项目概览

### 项目定位
面向内蒙古中小农畜产品企业的**SaaS化AI营销赋能平台**，通过文化IP智能体（小数/小商）+ 知识图谱 + 营销工具集，降低品牌营销门槛。

### 核心差异化
```
✅ 文化IP智能体    全国首个草原文化AI代言人
✅ 知识图谱赋能    产品-文化-品牌深度关联
✅ 营销闭环       从内容创作到效果监测
✅ 降本提效       替代3-5人营销团队
✅ 多模态AI       文本+图像+视频生成
```

### 项目目标（12周）
- **功能完整性**: IP智能体上线、知识图谱建立、营销工具完善
- **用户体验**: IP对话满意度≥4.0/5.0，内容生成质量≥80%
- **技术指标**: API响应<2s，AI成本<¥300/月
- **业务指标**: IP对话≥500次/周，品牌故事≥50篇

## 💻 技术架构

### 技术栈
```
前端: Vue 3 + TypeScript + Element Plus + Vite
后端: Python 3.11 + FastAPI + SQLAlchemy + Pydantic
AI层: 
  - 文本生成: DeepSeek (主力, ¥0.001/千tokens)

  - 视频生成: 火山引擎即梦AI (¥2/分钟)

```

│ 订单/营销   │  知识图谱     │ Redis       │

│             │  (DeepSeek/   │             │

## 🎯 关键功能模块

### 1. IP智能体系统

**小数（草原文化传承者）**
- 角色定位: 蒙古族青年，草原文化专家
- 语言风格: "咱们草原上..."、"就像老额吉说的..."
- 核心能力: 产品咨询、品牌故事、文化溯源、选购建议

**小商（品牌营销顾问）**
- 角色定位: 专业营销顾问
- 语言风格: "根据我们的分析..."、"建议您..."
- 核心能力: 直播脚本、营销策略、平台适配、数据分析

**技术实现**
```python
AIProviderManager (统一管理)
    ├─ DeepSeekProvider (主力LLM)
    ├─ ClaudeProvider (备选LLM)
    └─ VolcengineProvider (图像/视频)

IPRouter
    ├─ intent_detection(user_message)
    ├─ XiaoshuAgent
    └─ XiaoshangAgent
```

### 2. 知识图谱

**数据模型**
```
产品 ──属于→ 品类
  │           │
产地         品牌
  │
文化元素 (15个)
  ├─ 节日: 那达慕、敖包祭祀、白月节
  ├─ 技艺: 蒙古族摔跤、赛马、刺绣
  ├─ 美食: 手把肉、奶茶文化
  └─ 故事: 敕勒川、昭君出塞
```

**核心功能**
- 产品文化溯源（产品→产地→文化→故事）
- 文化元素推荐
- 品牌故事自动生成

### 3. 营销工具集

| 工具 | 功能 | 输入 | 输出 |
|-----|------|------|------|
| 品牌故事生成 | 融入文化元素的品牌故事 | 产品信息 | 300-500字故事 |
| 直播脚本生成 | 分镜级直播脚本 | 产品+平台+时长 | 完整脚本表格 |
| 多平台适配 | 一键生成多平台内容 | 原始内容+平台 | 适配内容 |
| 产品图片生成 | 营销海报/产品图 | 文字描述+风格 | 高清图片 |
| 宣传视频生成 | 产品宣传短视频 | 文字描述+时长 | 视频+缩略图 |
| 效果监测 | AI使用统计+成本分析 | - | 数据看板 |

## 💰 成本预算

### 开发成本（3个月）
| 类别 | 明细 | 金额 |
|-----|------|------|
| 人力 | 学生团队（4-5人） | - |
| AI服务 | DeepSeek (¥500/月) + 火山引擎 (¥150/月) | ¥650/月 × 3 = ¥1,950 |
| 服务器 | 轻量应用云服务器（年付） | ¥1,080 |
| 存储 | 对象存储150GB | ¥18/月 × 3 = ¥54 |
| 域名SSL | 域名+SSL证书（年付） | ¥74.60 |
| **合计** | | **¥3,158.60** |

**成本对比**（vs 原Claude方案）:
- 原方案（Claude + 无图像/视频）: ¥7,300
- 新方案（DeepSeek + 火山引擎）: ¥3,158.60
- **节省**: 57% (¥4,141.40)

### 成本优化策略
- LLM缓存命中率≥50%，节省¥100+/月
- Prompt优化，减少Token消耗20-30%
- 图像/视频缓存7天，避免重复生成
- 简单问答模板回复，降级机制
