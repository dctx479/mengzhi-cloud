## 📊 核心数据速览

### 项目规模
- **开发周期**: 12周（2026-06-11 至 2026-09-03）
- **团队规模**: 4-5人（240-300人日）
- **代码行数预估**: 后端5000行，前端3000行
- **预算**: ¥7300（3个月）

### 技术栈
```
前端: Vue 3 + TypeScript + Element Plus
后端: FastAPI + PostgreSQL + Redis
AI:   Claude Sonnet 4.6
部署: Docker Compose
```

### 核心功能
1. **IP智能体**: 小数（文化传承）+ 小商（营销顾问）
2. **知识图谱**: 15个文化元素 + 产品溯源
3. **营销工具**: 品牌故事 + 直播脚本 + 平台适配

### 质量目标
- 代码覆盖率 ≥60%
- API响应 P95<2s
- 用户满意度 ≥4.0/5.0
- AI成本 <¥2000/月
