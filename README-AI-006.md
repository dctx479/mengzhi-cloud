## 使用速查

### 5分钟快速开始

```bash
# 1. 集成API端点
from app.api.v1.prompts import router as prompts_router
app.include_router(prompts_router)

# 2. 快速调用
response = requests.post(
    "http://localhost:8000/api/v1/prompts/product-copy/quick",
    json={
        "product_name": "内蒙古有机黄油",
        "category": "乳制品",
        "key_features": ["有机认证", "无添加"],
        "target_segment": "高端消费者",
        "style": "professional",
        "word_count": 300
    }
)
prompt = response.json()["prompt"]

# 3. 调用AI模型生成内容
content = ai_model.generate(prompt)
```

### 15分钟完整流程

```python
from app.services.ai.prompt_manager import (
    PromptTemplateManager,
    PromptContextBuilder
)

# 初始化管理器
manager = PromptTemplateManager()

# 构建上下文
context = PromptContextBuilder.build_product_copy_context(
    product_name="内蒙古有机黄油",
    category="乳制品",
    origin="内蒙古鄂尔多斯",
    features="有机认证、无添加、传统工艺",
    cultural_background="源自游牧民族千年技艺",
    target_audience="30-50岁高端消费者",
    word_count=300
)

# 验证上下文
is_valid, missing, msg = manager.validate_context('product_copy', context)

# 渲染Prompt
if is_valid:
    prompt = manager.render_prompt(
        template_type='product_copy',
        style='professional',
        context=context
    )
    # 调用LLM
    result = llm.generate(prompt)
```
