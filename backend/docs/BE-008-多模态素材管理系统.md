# 多模态素材管理系统 (BE-008)

## 概述

多模态素材管理系统为平台提供完整的媒体文件管理功能，支持图片、视频的上传、存储、管理和CDN加速。

## 功能特性

### 1. 文件上传
- **图片上传**：支持 JPEG、PNG、WebP、GIF
- **视频上传**：支持 MP4、MPEG、MOV
- **文件大小限制**：图片最大 50MB，视频最大 200MB
- **自动处理**：自动压缩、生成缩略图

### 2. 存储方式
- **本地存储**：默认存储在 `uploads/` 目录
- **对象存储**：支持阿里云 OSS、腾讯云 COS（可配置）
- **目录组织**：按分类和日期自动组织文件

### 3. 媒体分类
- **product**：产品图片/视频
- **culture**：文化素材
- **certificate**：证书资质
- **user_avatar**：用户头像
- **other**：其他

### 4. 功能支持
- 媒体列表查询（分页、筛选）
- 媒体详情获取
- 媒体信息更新
- 媒体删除（物理删除）
- 产品关联管理
- 媒体统计


- `page`: 页码（默认 1）
- `page_size`: 每页大小（默认 20，最大 100）

**响应示例：**


## 数据模型

### Media 表结构
```sql
CREATE TABLE media (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  media_uuid VARCHAR(36) UNIQUE NOT NULL,

  -- 文件信息
  filename VARCHAR(255) NOT NULL,
  file_path VARCHAR(500) NOT NULL,
  file_url VARCHAR(500) NOT NULL,
  file_size BIGINT NOT NULL,
  mime_type VARCHAR(100) NOT NULL,

  -- 分类
  media_type ENUM('image', 'video', 'audio', 'document') NOT NULL,
  category ENUM('product', 'culture', 'certificate', 'user_avatar', 'other') NOT NULL,

  -- 元数据
  width INT,
  height INT,
  duration INT,
  thumbnail_url VARCHAR(500),

  -- 关联
  product_id BIGINT,
  user_id BIGINT NOT NULL,

  -- 描述
  title VARCHAR(200),
  description TEXT,
  alt_text VARCHAR(200),

  -- 状态
  is_public BOOLEAN DEFAULT TRUE,
  is_processed BOOLEAN DEFAULT FALSE,

  -- 时间戳
  created_at DATETIME NOT NULL,
  updated_at DATETIME NOT NULL,
  deleted_at DATETIME,

  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE SET NULL,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,

  INDEX idx_media_type (media_type),
  INDEX idx_category (category),
  INDEX idx_user_id (user_id),
  INDEX idx_product_id (product_id)
);
```

## 权限控制

### 用户权限
- **普通用户**：只能查看、管理自己上传的媒体
- **企业用户**：可以将媒体关联到自己创建的产品
- **管理员**：可以查看、管理所有用户的媒体

### 操作权限矩阵
| 操作 | 普通用户 | 企业用户 | 管理员 |
|------|---------|---------|--------|
| 上传媒体 | ✓ | ✓ | ✓ |
| 查看自己的媒体 | ✓ | ✓ | ✓ |
| 查看他人的媒体 | ✗ | ✗ | ✓ |
| 更新自己的媒体 | ✓ | ✓ | ✓ |
| 删除自己的媒体 | ✓ | ✓ | ✓ |
| 关联到产品 | ✗ | ✓ | ✓ |

## 使用示例

### Python 客户端示例
```python
import requests

# 1. 上传图片
files = {
    'file': open('product.jpg', 'rb')
}
data = {
    'category': 'product',
    'title': '产品主图',
    'description': '这是产品的主图片'
}
headers = {
    'Authorization': 'Bearer your_token'
}

response = requests.post(
    'http://localhost:8000/api/v1/media/upload/image',
    files=files,
    data=data,
    headers=headers
)

print(response.json())

# 2. 获取媒体列表
response = requests.get(
    'http://localhost:8000/api/v1/media/',
    params={'media_type': 'image', 'category': 'product'},
    headers=headers
)

print(response.json())
```
