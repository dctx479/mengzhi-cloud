# 多模态素材管理系统 (BE-008)

## 概述

多模态素材管理系统为平台提供完整的媒体文件管理功能，支持图片、视频的上传、存储、管理和CDN加速。

## 功能特性

### 0. AI 媒体生成
- **图片生成**：支持通义万相真实提交/查询，支持文心一格、讯飞星火绘画通过通用 HTTP Provider 配置化接入
- **视频生成**：支持剪映开放平台、腾讯智影通过通用 HTTP Provider 配置化接入
- **管理员配置**：支持服务商 API Key 加密存储、启停、主备、优先级、成本、健康状态
- **异步任务**：支持提交任务、查询任务状态、保存生成结果、成本统计
- **安全约束**：API Key 不在接口响应中返回，服务商调用失败会落库为失败任务

### 1. 文件上传
- **图片上传**：支持 JPEG、PNG、WebP、GIF
- **视频上传**：支持 MP4、MPEG、MOV
- **文件大小限制**：图片最大 50MB，视频最大 200MB
- **自动处理**：自动压缩、生成缩略图

### 2. 存储方式
- **本地存储**：默认存储在 `uploads/` 目录
- **对象存储**：支持阿里云 OSS、腾讯云 COS（可配置）
- **目录组织**：按分类和日期自动组织文件

### 3. 媒体分类
- **product**：产品图片/视频
- **culture**：文化素材
- **certificate**：证书资质
- **user_avatar**：用户头像
- **other**：其他

### 4. 功能支持
- 媒体列表查询（分页、筛选）
- 媒体详情获取
- 媒体信息更新
- 媒体删除（物理删除）
- 产品关联管理
- 媒体统计

### AI 媒体生成接口

#### 管理员服务商配置

```http
GET    /api/v1/ai-media/admin/media-providers
POST   /api/v1/ai-media/admin/media-providers
PUT    /api/v1/ai-media/admin/media-providers/{provider_id}
DELETE /api/v1/ai-media/admin/media-providers/{provider_id}
POST   /api/v1/ai-media/admin/media-providers/{provider_id}/test
POST   /api/v1/ai-media/admin/media-providers/{provider_id}/health-check
GET    /api/v1/ai-media/admin/media-generation/costs
```

创建通义万相图片服务商示例：

```json
{
  "providerCode": "tongyi_wanxiang",
  "providerName": "通义万相",
  "providerType": "image",
  "apiKey": "[服务商 API Key]",
  "apiEndpoint": "[通义万相任务提交地址]",
  "defaultModel": "wanx-v1",
  "isActive": true,
  "isPrimary": true,
  "priority": 100,
  "costPerUnit": 0.2,
  "rateLimitPerMinute": 60,
  "config": {
    "query_endpoint": "[通义万相任务查询地址，需包含 {task_id}]",
    "timeout": 30
  }
}
```

配置字段说明：

| 字段 | 说明 |
|------|------|
| `apiEndpoint` | 任务提交地址；也可用 `config.submit_endpoint` 覆盖 |
| `config.query_endpoint` | 任务查询地址，必须包含 `{task_id}` 占位符 |
| `config.validate_endpoint` | 可选配置验证地址；未配置时只做本地配置校验 |
| `config.headers` | 可选 HTTP 头，会合并到默认 `Authorization: Bearer {apiKey}` 与 `Content-Type: application/json` |
| `config.payload_template` | 可选提交请求模板，会与任务请求字段合并，任务请求字段优先 |
| `defaultModel` / `config.model` | 默认模型，任务未指定模型时使用 |
| `isPrimary` | 同类型媒体的默认主服务商 |
| `priority` | 非指定服务商时的选择优先级 |
| `costPerUnit` | 图片按张计费，视频按时长计费 |
| `rateLimitPerMinute` | 管理端配置限流参考值 |
| `config.timeout` | Provider HTTP 调用超时时间，单位秒 |

通用 HTTP Provider 配置示例：

```json
{
  "providerCode": "wenxin_yige",
  "providerName": "文心一格",
  "providerType": "image",
  "apiKey": "[服务商 API Key]",
  "apiEndpoint": "[服务商任务提交地址]",
  "defaultModel": "[默认模型名称]",
  "isActive": true,
  "isPrimary": false,
  "priority": 80,
  "costPerUnit": 0.2,
  "rateLimitPerMinute": 60,
  "config": {
    "query_endpoint": "[服务商任务查询地址，需包含 {task_id}]",
    "validate_endpoint": "[可选：服务商配置验证地址]",
    "headers": {
      "X-App-Id": "[可选：服务商要求的应用标识]"
    },
    "payload_template": {
      "quality": "high"
    },
    "timeout": 30
  }
}
```

通用 HTTP Provider 当前适用于文心一格、讯飞星火绘画、剪映开放平台、腾讯智影。不同厂商如有专用签名、鉴权或字段映射要求，应在拿到官方文档后补充定制 Provider 实现。

创建图片生成任务示例：

```json
{
  "prompt": "草原羊肉品牌海报",
  "negativePrompt": "低清晰度",

  "model": "wanx-v1",
  "width": 1024,
  "height": 1024,
  "resultCount": 2,
  "params": {
    "style": "realistic"
  }

```

任务状态：

| 状态 | 含义 |
|------|------|
| `pending` | 已创建，待提交 |
| `processing` | 服务商处理中 |
| `succeeded` | 生成成功，结果已保存 |
| `failed` | 生成失败，`error_message` 保存失败原因 |
| `canceled` | 用户取消 |

## 数据模型

### Media 表结构
```sql
CREATE TABLE media (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  media_uuid VARCHAR(36) UNIQUE NOT NULL,

  -- 文件信息
  filename VARCHAR(255) NOT NULL,
  file_path VARCHAR(500) NOT NULL,
  file_url VARCHAR(500) NOT NULL,
  file_size BIGINT NOT NULL,
  mime_type VARCHAR(100) NOT NULL,

  -- 分类
  media_type ENUM('image', 'video', 'audio', 'document') NOT NULL,
  category ENUM('product', 'culture', 'certificate', 'user_avatar', 'other') NOT NULL,

  -- 元数据
  width INT,
  height INT,
  duration INT,
  thumbnail_url VARCHAR(500),

  -- 关联
  product_id BIGINT,
  user_id BIGINT NOT NULL,

  -- 描述
  title VARCHAR(200),
  description TEXT,
  alt_text VARCHAR(200),

  -- 状态
  is_public BOOLEAN DEFAULT TRUE,
  is_processed BOOLEAN DEFAULT FALSE,

  -- 时间戳
  created_at DATETIME NOT NULL,
  updated_at DATETIME NOT NULL,
  deleted_at DATETIME,

  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE SET NULL,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,

  INDEX idx_media_type (media_type),
  INDEX idx_category (category),
  INDEX idx_user_id (user_id),
  INDEX idx_product_id (product_id)
);
```

## 权限控制

### 用户权限
- **普通用户**：只能查看、管理自己上传的媒体
- **企业用户**：可以将媒体关联到自己创建的产品
- **管理员**：可以查看、管理所有用户的媒体

### 操作权限矩阵
| 操作 | 普通用户 | 企业用户 | 管理员 |

## 使用示例

### Python 客户端示例
```python
import requests

# 1. 上传图片
files = {
    'file': open('product.jpg', 'rb')
}
data = {
    'category': 'product',
    'title': '产品主图',
    'description': '这是产品的主图片'
}
headers = {
    'Authorization': 'Bearer your_token'
}

response = requests.post(
    'http://localhost:8000/api/v1/media/upload/image',
    files=files,
    data=data,
    headers=headers
)

print(response.json())

# 2. 获取媒体列表
response = requests.get(
    'http://localhost:8000/api/v1/media/',
    params={'media_type': 'image', 'category': 'product'},
    headers=headers
)

print(response.json())
```
