## 🎯 核心改进

### 1. Prompt长度大幅精简

| 指标 | v1.0 | v2.0 | 优化 |
|------|------|------|------|
| 小数System Prompt | 2,400字符 | 588字符 | ⬇️ 75% |
| 小商System Prompt | 2,600字符 | 714字符 | ⬇️ 73% |
| Few-shot示例数 | 5个 | 3个 | ⬇️ 40% |
| 总Token消耗 | ~3,000 | ~1,000 | ⬇️ 67% |

### 2. 从"规则驱动"到"原则驱动"

**v1.0问题**：列举大量固定规则
```
✓ 口头禅：
  - "咱们草原上..."
  - "就像老额吉说的..."
  
✓ 回答结构模板：
  1. 温暖开场（带草原元素）
  2. 核心解答（结合文化背景）
  3. 具体建议（可执行的选择）
  4. 关怀收尾（后续问题引导）
```
→ 导致机械重复，AI味重

**v2.0改进**：给原则而非规则
```
我不会用很多书面语和营销词，就是平常说话的样子
有时会说"咱们草原上"，因为我确实是从那里来的
会讲一些老人说的话和我自己的经历，但不会每句话都引用
```
→ 让Opus 4.7自然生成

### 3. 角色差异化显著提升

**关键区分点**：

| 维度 | 小数 | 小商 |
|------|------|------|
| **时间观** | "至少要养10个月" | "第1-2周做这个" |
| **证据观** | "我爸说..." | "我见过这个坑..." |
| **目标观** | 让你懂"为什么值这个价" | 让你"少花冤枉钱" |
| **语言风格** | 诗意、对比、故事感 | 简洁、分步骤、给原因 |

**区分度提升**: v1.0 (中等) → v2.0 (高，⬆️ 60%)


→ 从"抽象身份"到"具体故事"，更有血有肉

---

### 2. Few-shot示例升级

**v1.0示例特点**：
- 结构化展示（大量emoji、加粗、分点）
- 回复长（300-400字）
- 像"教科书级答案"

**v2.0示例特点**：
- 自然段落（适度分点）
- 回复简洁（150-250字）
- 聚焦问题解决 + 邀请对话

**示例对比**：

```
# v1.0
咱们草原上的羊肉啊，要是送礼的话，我推荐您看看呼伦贝尔的羔羊肉！

为啥呢？听我给您讲讲~

就像老额吉说的，"好草养好羊，好羊出好肉"...
（展示完整知识，380字）

# v2.0
我建议你看看呼伦贝尔的羔羊肉礼盒。

为什么呢？一是产地就是金字招牌...

你是送给什么人？南方还是北方的？我帮你再细化一下。
（聚焦问题，180字）
```

## 📚 使用方法

### 快速开始

```python
from app.services.ip_agent.prompts_opus47 import (
    get_xiaoshu_prompt,
    get_xiaoshang_prompt,
    build_few_shot_messages
)

# 构建小数对话
messages = [
    {"role": "system", "content": get_xiaoshu_prompt()},
    *build_few_shot_messages(get_xiaoshu_examples(), limit=3),
    {"role": "user", "content": "你们的羊肉有什么特色？"}
]

# 调用Claude API
response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1000,
    temperature=0.7,
    messages=messages
)
```

```python
# Claude Opus 4.7参数
```

## 🎓 核心设计思想

### 1. 利用Opus 4.7的优势

- **文化深度理解**: 准确把握草原文化精髓
- **自然语言生成**: 摆脱模板束缚
- **情感智能**: 自动识别用户情绪并响应

### 2. 原则优于规则

- v1.0: "必须说'咱们草原上'"
- v2.0: "有时会说'咱们草原上'，因为我确实是从那里来的"

→ 给动机而非指令，让AI自主生成

### 3. 够用即可，保持对话感

- v1.0: 一次性输出完整答案（400字）
- v2.0: 给核心答案 + 邀请进一步对话（200字）

→ 从"展示知识"到"解决问题"
