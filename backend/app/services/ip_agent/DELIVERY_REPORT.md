## 🎯 三大核心洞察

### 洞察1: 价值转化缺口（小数）

**问题诊断**：
当前版本把"讲故事"当目标，用户听完后陷入"所以呢？"的困境。

**解决方案**：
重新定位为"产品价值翻译官"，建立转化链条：
```
草原文化元素 → 品质差异（可量化） → 购买理由（可验证） → 行动指南
```

**实战案例**：
```
❌ v1.0: "咱们草原上的羊吃碱草、喝雪水，就像老额吉说的..."
✅ v2.0: "呼伦贝尔羊365天出栏vs超市羊120天，导致肌肉纤维更细（涮5秒测试），
         建议您先买500g试试，不好吃可退。"
```

**关键改进**：
- 4步法回答结构（确认需求 → 解答 → 建议 → 行动）
- 每次回答必含：1个可验证事实 + 1个行动建议
- 3个场景化应对方案（价格质疑/产地纠结/真假辨别）

---

### 洞察2: 执行颗粒度不足（小商）

**问题诊断**：
"建议您..."式空洞建议，用户听完后不知道"具体怎么做"。

**解决方案**：
重新定位为"执行方案架构师"，输出可落地SOP：
```
策略建议 → 时间表（分阶段） → 成本拆解 → 验收指标（可量化） → 风险预警
```

**实战案例**：
```
❌ v1.0: "建议您做好内容定位，持续发布优质视频，适当投流..."
✅ v2.0: "90天路线图：
         第1-30天：投入2000元设备+600元投流，目标1000粉，验收指标：单条播放5000+
         第31-60天：爆款内容投DOU+ 1000元，开播测试，目标GMV 2-5万
         失败概率30%（内容不符合平台调性），备选方案：小红书种草"
```

**关键改进**：
- 5步法回答结构（诊断 → 策略 → 执行 → 验收 → 风险）
- 每次方案必含：时间表 + 成本 + 指标 + 失败率
- 4个高频场景话术库（冷启动/直播设计/数据诊断/危机应对）

---

### 洞察3: 场景覆盖盲区（双IP）

**问题诊断**：
缺失高频痛点场景：危机应对、竞品碰撞、ROI质疑、直播翻车。

**解决方案**：
构建场景化话术库，覆盖"正常流程"之外的异常情况。

**新增场景**：

**小数**：
- 场景A：价格质疑 → 价值拆解公式（成本对比+验证方法+降低门槛）
- 场景B：产地纠结 → 决策矩阵（口感×烹饪×人群）
- 场景C：跟进口羊肉比较 → 客观对比（不踩不捧）

**小商**：
- 场景A：预算不够 → 分级方案（<3k / 3-10k / >10k）
- 场景B：效果质疑 → 真实周期（不画饼，30/90天分段）
- 场景C：直播翻车 → 3分钟黄金应急话术（托/假货/恶意刷屏）

## 🚀 使用方式

### 快速启动

```python
from backend.app.services.ip_agent.prompts_opus48 import (
    get_xiaoshu_prompt,
    get_xiaoshang_prompt,
    build_few_shot_messages,
    get_xiaoshu_examples
)

# 1. 获取System Prompt
system_prompt = get_xiaoshu_prompt()

# 2. 构建Few-shot消息（推荐3个示例）
few_shot_messages = build_few_shot_messages(get_xiaoshu_examples(), limit=3)

# 3. 组合API调用
messages = [
    {"role": "system", "content": system_prompt},
    *few_shot_messages,
    {"role": "user", "content": user_input}
]

# 4. 调用Claude API
response = client.messages.create(
    model="claude-opus-4-8",
    messages=messages,
    max_tokens=2000
)
```
