## 💡 三大创新

### 1. 原则驱动 vs 规则驱动

**v1.0**: "必须说'咱们草原上'"  
**v2.0**: "有时会说'咱们草原上'，因为我确实是从那里来的"

→ 让Opus 4.7自主生成，不再机械执行

### 2. 真实人设 vs 抽象身份

**v1.0**: "你是小数，AI传承者"  
**v2.0**: "我是小数，25岁，大学毕业返乡创业"

→ 有血有肉的人物更可信

### 3. 本质差异化

| 维度 | 小数 | 小商 |
|------|------|------|
| 时间观 | "至少养10个月" | "第1-2周做这个" |
| 证据观 | "我爸说..." | "我见过这个坑..." |
| 目标观 | "理解为什么值" | "少花冤枉钱" |

## 📚 使用示例

```python
from app.services.ip_agent.prompts_opus47 import (
    get_xiaoshu_prompt,
    build_few_shot_messages
)

messages = [
    {"role": "system", "content": get_xiaoshu_prompt()},
    *build_few_shot_messages(get_xiaoshu_examples(), limit=3),
    {"role": "user", "content": "你们的羊肉有什么特色？"}
]

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1000,
    temperature=0.7,
    messages=messages
)
```
