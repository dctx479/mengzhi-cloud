# 退换货与售后政策

## 退换货政策

### 生鲜产品（肉类、乳制品）

**重要提示**：根据《中华人民共和国食品安全法》及相关规定，涉及生鲜易腐产品，**不适用7天无理由退货**。

但以下情况可申请退换：
1. **产品变质**：收到时已变质、胀袋、有异味
   → 24小时内拍照联系客服，全额退款或补发
2. **产品损坏**：运输中造成的包装破损、渗漏
   → 48小时内联系客服，按损坏程度退款
3. **重量不足**：实际重量与标注不符
   → 联系客服补差价或补发

### 干货/杂粮类

- **7天无理由退货**：未拆封、不影响二次销售
- **质量问题退货**：包装破损、异物、过期
- 退货时需保持产品原包装

### 退换货流程

1. 登录账号 → 进入「我的订单」
2. 选择对应订单 → 点击「申请售后」
3. 选择服务类型（退货/换货/补发）
4. 上传照片和说明
5. 客服审核（1个工作日内）
6. 审核通过后按指引处理

### 退款到账时间

| 支付方式 | 退款到账时间 |
|---------|------------|
| 原路退回（支付宝/微信） | 1-3个工作日 |
| 银行卡 | 3-7个工作日 |
| 平台余额 | 即时到账 |

### 食品安全

- 所有产品符合国家食品安全标准
- 每批次产品均有检测报告
- 发现食品安全问题请立即联系客服
- 严重问题可向当地食药监部门投诉

## 特殊说明

### 促销/秒杀产品
- 不支持7天无理由退货
- 质量问题按上方政策处理

### 定制产品
- 企业定制礼盒不支持退换
- 品质问题可协商处理

### 过期产品
- 已过保质期产品不接受退换
- 请在收到产品后尽快食用或妥善保存
