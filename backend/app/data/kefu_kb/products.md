# 内蒙古农畜产品知识库

## 产品分类

### 牛羊肉类

#### 草原羊
- **产地**: 内蒙古锡林郭勒草原、呼伦贝尔草原
- **品种**: 乌珠穆沁羊、苏尼特羊、呼伦贝尔羊
- **特点**: 天然放牧，肉质鲜嫩，无膻味，富含蛋白质和氨基酸
- **规格**: 整羊、羊腿、羊排、羊肉卷、羊蝎子
- **价格**: 根据部位不同，羊腿约 ¥68/斤，羊排约 ¥75/斤

#### 草原牛肉
- **产地**: 科尔沁草原、锡林郭勒
- **品种**: 科尔沁黄牛、西门塔尔牛
- **特点**: 草饲放养，肉质紧实，富含铁和锌
- **规格**: 牛腩、牛里脊、牛腱子、牛排
- **价格**: 牛腩约 ¥48/斤，牛排约 ¥98/斤

### 奶制品

#### 草原牛奶
- **产地**: 呼伦贝尔、锡林郭勒
- **特点**: 原生态、无添加、高蛋白（3.2g/100ml）
- **规格**: 袋装（1L）、瓶装（500ml）
- **保质期**: 冷藏7天

#### 奶酪/干酪
- **品种**: 蒙古切达奶酪、草原大孔奶酪
- **特点**: 传统工艺发酵，口感醇厚
- **规格**: 块装（200g/500g）
- **保质期**: 常温6个月

#### 酸奶
- **特点**: 发酵型酸奶，含有益生菌
- **规格**: 杯装（200g）、瓶装（1L）
- **保质期**: 冷藏14天

### 杂粮/主食

#### 藜麦
- **产地**: 乌兰察布、赤峰
- **特点**: 营养价值高，蛋白质含量达16%，含有全部9种必需氨基酸
- **规格**: 袋装（500g/1kg）
- **食用方法**: 煮粥、拌沙拉、米饭代餐

#### 敖汉小米
- **产地**: 赤峰市敖汉旗（国家地理标志产品）
- **特点**: 金黄色，口感绵软，富含维生素B1
- **规格**: 袋装（1kg/2.5kg）
- **食用方法**: 煮小米粥、做小米饭

#### 荞麦
- **产地**: 呼伦贝尔、兴安盟
- **特点**: 含膳食纤维，适合三高人群
- **规格**: 袋装（1kg）

## 常见问题

### 如何选购牛羊肉？
1. 看颜色：优质羊肉呈淡红色，牛肉呈深红色
2. 看纹理：肉质纹理清晰，脂肪分布均匀
3. 闻气味：无异味，有草原清香
4. 看弹性：按压后快速恢复

### 藜麦怎么吃？
1. 提前浸泡2小时
2. 按1:2比例加水煮熟（约15分钟）
3. 可搭配水果、酸奶做成藜麦沙拉
4. 可与大米混合煮饭（1:2比例）

### 小米怎么分辨优劣？
1. 优质小米颜色金黄均匀
2. 颗粒饱满，大小一致
3. 煮粥后汤色浓稠，米油丰富
4. 敖汉小米特有的绵软口感是辨别标志

### 产品保质期是多久？
- 生鲜肉制品：冷藏3-5天，冷冻12个月
- 奶制品：根据包装标识，通常7-30天
- 杂粮干货：常温保存12个月
