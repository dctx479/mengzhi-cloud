# 下单与支付指南

## 下单流程

### 零售下单

1. **浏览产品**: 在产品列表选择心仪的产品
2. **加入购物车**: 点击「加入购物车」或「立即购买」
3. **确认订单**: 填写收货地址，选择配送方式
4. **选择支付**: 选择支付方式并完成支付
5. **等待发货**: 支付成功后等待商家发货
6. **确认收货**: 收到货后确认无误点「确认收货」

### 企业采购/团购

1. 联系客服获取企业报价
2. 确认订单内容和价格
3. 签订采购合同（如需要）
4. 支付定金或全款
5. 按约定时间配送

## 支付方式

### 个人支付

| 方式 | 说明 | 到账时间 |
|------|------|---------|
| 支付宝 | 扫码/APP支付 | 即时 |
| 微信支付 | 扫码/APP支付 | 即时 |
| 银行卡 | 储蓄卡/信用卡 | 即时 |
| 平台余额 | 账户余额支付 | 即时 |

### 企业支付

- **对公转账**:
  - 账户信息在订单确认页显示
  - 转账时备注订单号
  - 财务确认后1个工作日内生效
- **月结**: 针对信用良好的企业客户，可申请月结

### 分期付款

- 支付宝花呗、京东白条支持分期
- 信用卡分期支持3/6/12期
- 部分产品支持免息分期

## 发票

### 发票类型

- **电子发票**: 推荐，1个工作日内发送到邮箱
- **纸质发票**: 随包裹寄出或单独邮寄

### 发票内容

- 普票/增值税普通发票
- 增票/增值税专用发票（需提供资质证明）

### 开票流程

1. 结算页面勾选「需要发票」
2. 填写发票抬头信息
3. 确认订单后1个工作日发送

### 补开发票

- 下单后30天内可申请补开
- 进入「我的订单」→ 订单详情 → 「申请开票」

## 价格与优惠

### 会员价格

| 会员等级 | 折扣 |
|---------|------|
| 普通会员 | 无折扣 |
| 银牌会员 | 9.5折 |
| 金牌会员 | 9折 |
| 企业客户 | 批量报价 |

### 优惠活动

- **新人礼**: 新用户首单满100减20
- **满减**: 满299减30，满499减60
- **节日促销**: 中秋/春节等节日特惠
- **会员日**: 每月15日会员专享折扣

### 优惠券

1. 领取优惠券（活动页面/客服发放）
2. 结算时选择使用优惠券
3. 优惠券不可叠加，每单限用1张
4. 部分商品/活动不可用券

## 订单管理

### 订单状态

待支付 → 已支付 → 已发货 → 运输中 → 已签收

### 修改订单

- **未支付**: 可直接修改收货地址、发票
- **已支付未发货**: 可联系客服修改地址
- **已发货**: 不可修改，等待签收后处理

### 取消订单

- **未支付**: 可直接取消
- **已支付未发货**: 可取消，退款7天内到账
- **已发货**: 不可取消，需等签收后退货
