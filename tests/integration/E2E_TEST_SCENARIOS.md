## 场景1: 新用户注册登录流程

### 场景描述
新用户首次访问平台，完成注册、登录、浏览产品的完整流程。

### 测试目标
- 验证用户注册功能
- 验证登录认证流程
- 验证首次登录体验
- 验证基础功能可访问性

### 前置条件
- 后端服务运行正常
- 前端服务运行正常
- 数据库已初始化
- 邮箱服务可用（如需验证）

### 测试步骤

#### 步骤1: 访问首页
```
操作: 打开浏览器，访问 http://localhost:5173
验证:
  ✓ 页面正常加载
  ✓ 显示登录/注册按钮
  ✓ 显示产品列表（公开访问）
  ✓ 页面无控制台错误
```

#### 步骤2: 点击注册
```
操作: 点击"注册"按钮
验证:
  ✓ 跳转到注册页面 /auth/register
  ✓ 显示注册表单
  ✓ 表单包含：邮箱、密码、确认密码、用户名
  ✓ 显示验证码输入框
```

#### 步骤3: 填写注册信息
```
操作: 填写注册表单
输入数据:
  - 邮箱: test_user_001@example.com
  - 用户名: TestUser001
  - 密码: Test123!@#
  - 确认密码: Test123!@#
  - 验证码: [从图片识别]

验证:
  ✓ 实时验证邮箱格式
  ✓ 实时验证密码强度
  ✓ 确认密码匹配验证
  ✓ 验证码图片可刷新
```

#### 步骤4: 提交注册
```
操作: 点击"注册"按钮
验证:
  ✓ 显示加载状态
  ✓ API请求: POST /api/v1/auth/register
  ✓ 返回201状态码
  ✓ 显示注册成功提示
  ✓ 自动跳转到登录页面
```

#### 步骤5: 登录
```
操作: 在登录页面输入刚注册的账号
输入数据:
  - 邮箱: test_user_001@example.com
  - 密码: Test123!@#

验证:
  ✓ API请求: POST /api/v1/auth/login
  ✓ 返回200状态码和Token
  ✓ Token存储到localStorage
  ✓ 显示登录成功提示
  ✓ 跳转到首页
```

#### 步骤6: 验证登录状态
```
操作: 查看首页
验证:
  ✓ 显示用户头像/用户名
  ✓ 显示"退出登录"按钮
  ✓ 可访问用户中心
  ✓ 后续请求携带Authorization头
```

#### 步骤7: 浏览产品
```
操作: 点击产品列表中的产品
验证:
  ✓ 跳转到产品详情页
  ✓ 显示产品完整信息
  ✓ 显示文化标签
  ✓ 显示"AI咨询"按钮
```

#### 步骤8: 退出登录
```
操作: 点击"退出登录"
验证:
  ✓ API请求: POST /api/v1/auth/logout
  ✓ 清除localStorage中的Token
  ✓ 跳转到登录页面
  ✓ 无法访问需要认证的页面
```

### 预期结果
- ✅ 注册成功，用户数据正确存储
- ✅ 登录成功，Token正确生成
- ✅ 登录状态正确维护
- ✅ 退出登录正确清理状态

### 异常场景测试

#### 异常1: 邮箱已存在
```
操作: 使用已注册邮箱再次注册
验证:
  ✓ 显示"邮箱已被注册"错误
  ✓ 不创建新用户
  ✓ 提示用户登录或找回密码
```

#### 异常2: 密码错误
```
操作: 使用错误密码登录
验证:
  ✓ 显示"邮箱或密码错误"
  ✓ 不返回Token
  ✓ 记录失败次数
  ✓ 5次失败后锁定账号
```

#### 异常3: 验证码错误
```
操作: 输入错误验证码
验证:
  ✓ 显示"验证码错误"
  ✓ 刷新验证码
  ✓ 不提交注册请求
```

### 测试环境准备
```bash
# 1. 启动后端
cd backend
uvicorn app.main:app --reload --port 8000

# 2. 启动前端
cd frontend
npm run dev

# 3. 准备测试数据
python scripts/seed_data.py
```

### 测试执行
```bash
# 手动测试：按照场景步骤逐一执行
# 自动化测试：运行E2E测试脚本
cd tests/integration
python scripts/test_e2e_scenarios.py
```

### 测试记录
每个场景测试完成后，记录：
- ✅ 通过的步骤
- ❌ 失败的步骤
- 🐛 发现的Bug
- 📝 改进建议
- 📸 截图证据

### 测试报告
生成测试报告：
```bash
python scripts/generate_e2e_report.py
```
