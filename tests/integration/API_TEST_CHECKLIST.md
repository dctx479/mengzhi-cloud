## 5. 测试执行指南

### 前置条件
```bash
# 1. 启动后端服务
cd backend
uvicorn app.main:app --reload --port 8000

# 2. 确保数据库和Redis运行
docker-compose up -d mysql redis

# 3. 初始化测试数据
python scripts/seed_data.py
```

### 执行测试
```bash
# 执行所有API测试
cd tests/integration
python scripts/test_api_integration.py

# 执行特定模块测试
```
