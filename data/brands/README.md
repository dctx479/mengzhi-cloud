## 概述

这是内蒙古农畜产品品牌营销AI赋能云平台的**核心品牌产品数据集**，采集了内蒙古主要企业品牌的代表性产品，覆盖知名度高、市场份额大的品牌。

### 数据构成

| 层级 | 品牌数 | 产品数 | 特点 |
|-----|--------|--------|------|
| **一线品牌** | 10家 | 298个 | 全国知名、市场领导者 |
| **二线品牌** | 20家 | 198个 | 区域知名、地方特色 |
| **新兴品牌** | 10家 | 102个 | 创新驱动、有机认证 |
| **总计** | 40家 | 598个 | 完整的品牌生态 |

#### 3. `emerging_brands.json` - 新兴品牌产品集
- **规模**：10个品牌，102个产品

- **用途**：新品推荐、健康食品、电商品牌

**品牌类型**：

#### 5. `brand_stories.json` - 品牌故事集

## 应用场景

### 1. 产品推荐
```
用户："推荐一个内蒙古的高端牛奶"
AI："建议您选择蒙牛特仑苏或伊利金典...
   蛋白质含量≥3.3g/100ml，获得奥运会供应商认证..."
```

### 2. 品牌对比
```
用户："蒙牛和伊利的纯牛奶有什么区别？"
AI："蒙牛特仑苏：高端定位，蛋白质≥3.3g...
   伊利金典：有机认证，蛋白质≥3.6g..."
```

### 3. 新兴品牌推荐
```
用户："有没有新的有机品牌推荐？"
AI："推荐盛康有机，成立于2015年...
   所有产品获得有机认证，无激素、无农残..."
```

### 4. 地方特色推荐
```
用户："通辽有什么特产？"
AI："推荐科尔沁和牛眼肉...
   锡林郭勒羊肉获地理标志产品保护..."
```

### 5. 营销决策支持
```
企业："我们新产品应该如何定价？"
分析："参考蒙牛特仑苏12元/250ml...
   同类产品价格区间8-15元，建议10-13元..."
```

## 快速开始

### 1. 查找某个品牌

```bash
# 在tier1_brands.json中查找
{
  "brands": [
    {
      "brand_id": "T1_001",
      "brand_info": { "name": "蒙牛", ... },
      "products": [...]
    }
  ]
}
```

### 2. 查找某类产品

```bash
# 在brand_directory.json中查看分类统计
"by_category": {
  "乳制品": 280,
  "肉类制品": 120,
  "粮油制品": 90
}
```

### 3. 查找地区品牌

```bash
# 在brand_directory.json中查看地区分布
"by_region": {
  "呼和浩特市": 90,
  "通辽市": 95,
  "包头市": 75
}
```

### 4. 获取品牌故事

```bash
# 在brand_stories.json中查看品牌发展历程
{
  "brand_name": "蒙牛",
  "story": {
    "origin": "蒙牛乳业成立于1999年...",
    "development_phases": [...]
  }
}
```
