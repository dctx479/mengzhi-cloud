## 数据使用指南

### 1. JSON数据导入

#### Python示例
```python
import json

# 读取JSON文件
with open('batch1.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 访问产品数据
for product in data['products']:
    print(f"产品: {product['name']}")
    print(f"产地: {product['region']}")
    print(f"价格: {product['market_price_range']}")
```

#### JavaScript示例
```javascript
// 读取JSON文件
fetch('batch1.json')
  .then(response => response.json())
  .then(data => {
    data.products.forEach(product => {
      console.log(`${product.name}: ${product.market_price_range}`);
    });
  });
```
