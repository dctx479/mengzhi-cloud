## 技术实现

### 数据生成策略

1. **模板化生成**: 基于品类模板批量生成产品数据
2. **品类级别**: 同产品不同规格合并为variants
3. **质量保证**: 每个产品包含完整的字段信息
4. **官方数据优先**: 地理标志、认证产品100%来自官方数据库

### 数据结构

```json
{
  "product_id": "唯一标识",
  "name": "产品名称",
  "brand": "品牌",
  "category": "主分类",
  "subcategory": "子分类",
  "series": "系列",
  "price_range": "价格区间",
  "variants": [
    {"spec": "规格", "price": "价格"}
  ],
  "certifications": ["认证列表"],
  "sales_channels": ["销售渠道"],
  "data_quality": "数据质量等级"
}
```
