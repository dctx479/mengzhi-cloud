集成方式
================================================================================

1. 安装依赖
   pip install sentence-transformers faiss-cpu numpy

2. 添加路由 (在 app/main.py)
   from app.api.optimized_content import router as content_router
   app.include_router(content_router)

3. 配置环境 (.env)
   DEEPSEEK_API_KEY=your_key
   CACHE_ENABLED=true
   RAG_SIMILARITY_THRESHOLD=0.85

4. 启动服务
   python -m uvicorn app.main:app --reload

5. 测试API
   curl "http://localhost:8000/api/v1/content/generate?product_id=1"

使用指南
================================================================================

生成单个内容:
  curl -X POST http://localhost:8000/api/v1/content/generate \
    -G -d product_id=1 \
    -d content_type=copy \
    -d style=casual \
    -d platform=douyin \
    -d word_count=200

生成多个变体 (A/B测试):
  curl -X POST http://localhost:8000/api/v1/content/generate-variants \
    -G -d product_id=1 \
    -d count=3 \
    -d content_type=copy

支持的选项:
  - 内容类型: copy, script, video_copy, slogan, story
  - 风格: formal, casual, humorous, emotional, professional
  - 平台: douyin, xiaohongshu, wechat, weibo, kuaishou, general
